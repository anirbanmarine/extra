      Electrical Machines Revision Notes

      1. Transformers

      Principle: Static device that transfers AC electrical power between circuits via electromagnetic induction (Faraday’s Law) without changing frequency.

      • Core: Laminated silicon steel (0.3–0.5 mm) to minimize eddy current losses.
      • Types: Step-up/Step-down, Core-type / Shell-type, Single/Three-phase.

      • Faraday’s Law: e=−Ndϕdte = -N \frac{d\phi}{dt}e=−Ndtdϕ​

      • EMF Equation: E1=4.44fN1ΦmE_1 = 4.44 f N_1 \Phi_mE1​=4.44fN1​Φm​and E2=4.44fN2ΦmE_2 = 4.44 f N_2 \Phi_mE2​=4.44fN2​Φm​ (where fff = frequency, NNN = turns, Φm\Phi_mΦm​ = max flux)
      • Voltage Regulation: %VR=Vnl−VflVfl×100%\%VR = \frac{V_{nl} - V_{fl}}{V_{fl}} \times 100\%%VR=Vfl​Vnl​−Vfl​​×100%
      • Efficiency: η=PoutPin×100%=PoutPout+Pcu+Pcore×100%\eta = \frac{P_{out}}{P_{in}} \times 100\% = \frac{P_{out}}{P_{out} + P_{cu} + P_{core}} \times 100\%η=Pin​Pout​​×100%=Pout​+Pcu​+Pcore​Pout​​×100%
      • Max Efficiency Condition: Copper Loss ( I2RI^2RI2R) = Core (Iron) Loss

      🧪 Testing

      • Open Circuit (O.C.) Test: Done on HV side. Finds core losses, no-load current ( I0I_0I0​), and shunt parameters ( G0,B0G_0, B_0G0​,B0​).
      • Short Circuit (S.C.) Test: Done on LV side. Finds full-load copper losses and series impedance ( R01,X01R_{01}, X_{01}R01​,X01​).

      🔌 Special Transformers

      • Auto-transformer: Single winding acts as both primary and secondary. Economical for small voltage adjustments.
      • 3-Phase Connections: Y-Y, Y- Δ\DeltaΔ, Δ\DeltaΔ-Y, Δ\DeltaΔ- Δ\DeltaΔ. ( Δ\DeltaΔ- Δ\DeltaΔcan operate as “Open Delta” or V-V connection if one transformer fails).

      2. Induction Motors (IM)

      Principle: Stator’s 3-phase supply creates a Rotating Magnetic Field (RMF), which induces voltage and current in the short-circuited rotor, producing torque.

      • Construction:
        • Stator: Stationary, laminated core with 3-phase slots.
        • Rotor: Squirrel-cage (robust, low maintenance) or Wound-rotor (slip rings, external resistance possible).

      🔑 Key Formulas

      • Induced Torque: τind=k(BR×BS)\tau_{ind} = k (B_R \times B_S)τind​=k(BR​×BS​)
      • Starting Torque Relation: Tstart∝Vstart2∝Istart2T_{start} \propto V_{start}^2 \propto I_{start}^2Tstart​∝Vstart2​∝Istart2​

      🚦 Starting Methods (to limit high inrush current)

      1. D.O.L. (Direct-On-Line): Full voltage applied. Simple, cheap, but high starting current. Used for motors <5< 5<5kW.
      2. Star-Delta: Starts in Star (voltage per phase = 1/31/\sqrt{3}1/3​of rated), switches to Delta at ~80% speed. Reduces starting current and torque to 1/3 of DOL values.
      3. Auto-transformer Starter: Uses taps to reduce starting voltage. Suitable for large motors ( >20> 20>20kW).
      4. Rotor Resistance Starter: (Slip-ring only) Adds external resistance to increase starting torque and reduce starting current.
      5. Soft Starter: Uses back-to-back SCRs to smoothly ramp up voltage/current.

      🔄 Synchronous Motors

      Principle: Stator RMF locks with the DC-excited rotor poles.

      • Critical Trait: Not self-starting. Net average starting torque is zero because the torque reverses every half-cycle ( T∝sin⁡δT \propto \sin\deltaT∝sinδ), and rotor inertia prevents it from following the rapidly reversing field.

      Starting Methods:

      1. Damper Winding (Amortisseur): Copper bars embedded in rotor poles (acts like a squirrel-cage IM). Motor starts as an IM, and once near nsyncn_{sync}nsync​, DC is applied to “pull into synchronism”.
      2. Auxiliary Motor: A small AC/DC motor brings the synchronous motor to near synchronous speed before DC excitation is applied.
      3. Slip-Ring Induction Start: High external resistance is used to start as a wound-rotor IM, then switched to DC supply for synchronous operation.
